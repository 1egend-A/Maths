# `数据预处理代码/out/` 目录说明

**本目录里没有任何题目答案。**

这里放的是**阶段 0（数据管道）+ 阶段 0.5（预处理）** 的全部输出：读进来的数据、
验收报告、诊断记录。用途是**证明数据被正确读懂了**，以及**支撑论文的「数据预处理」章节**。

> ⚠️ 本目录中所有 `.txt` 若出现金额、SOC、功率等数字，都是**管道自检的副产物**
> （如「用 2025-01-01 跑一次 LP 看费用能不能复算一致」），
> **不是 Q1–Q4 的求解结果**，不要写进论文、不要当提交内容。
> `g0_feb01.txt` / `p0_check_report.txt` 这两个含真实数字的文件，文件首部已内置免责横幅。

## 4. 这批文件里被引用过的数字，只有两类

1. **客观数据事实**（可以进论文）：各附件的实测范围、附件3 的 RMSE 对比、附件5 的列结构。
   → 见 `p0_check_report.txt`、`diag_pv_quality.txt`、`probe_a5*.txt`、`calib_fc_offset.txt`。
2. **管道自检的副产物**（不要引用）：`2025-01-01` 单日 LP 的费用、`g0_feb01.txt` 里的
   1 月费用与 SOC。它们只用来验证「引擎能跑通、费用能复算」。
