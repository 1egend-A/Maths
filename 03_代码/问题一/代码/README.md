# 2026 高教社杯全国大学生数学建模竞赛 C题——问题一全部 MATLAB 代码

## 1. 文件说明

- `run_q1_all.m`  
  一键执行全部流程。

- `q1_preprocess.m`  
  读取附件1、统一144个10分钟时段、检查数值并生成标准化数据。

- `q1_solve.m`  
  建立并求解问题一线性规划模型，输出完整购电、充电、放电、SOC及费用结果。

- `q1_validate.m`  
  独立验证功率平衡、SOC递推、容量/功率边界、首末SOC和费用复算。

- `q1_export_result1.m`  
  将结果写入官方 `result1.xlsx` 模板。

- `q1_visualization.m`  
  生成论文使用的典型日曲线、最优调度/SOC图和费用对比图。

- `q1_make_flowchart.m`  
  生成问题一简洁横向流程图。

## 2. 运行环境

建议：
- MATLAB R2020b 或更高版本；
- Optimization Toolbox；
- Windows 中文环境（图片默认使用 Microsoft YaHei 字体）。

## 3. 使用方法

将下列两个原始文件放到 `code` 文件夹中：

1. `附件1.xlsx`
2. `result1.xlsx`（官方模板）

然后在 MATLAB 中进入该目录，运行：

```matlab
run_q1_all
```

## 4. 本代码采用的建模口径

- 时间步长：10分钟，`dt = 1/6 h`。
- 附件1的 `00:10` 表示区间 `00:00-00:10`，即采用右端点口径。
- 储能充、放电效率均取 `0.90`。
- 储能状态：
  `S_t = S_{t-1} + (0.9*c_t - d_t/0.9)*dt`。
- SOC区间：`1200 ~ 10800 kWh`。
- 最大充/放电功率：`5000 kW`。
- 问题一：`S_0 = S_24 = 6000 kWh`。
- 不允许向外网售电，富余光伏可弃用。
- 目标：最小化全天计划购电费用。
- 由于效率小于1，最优解中通常不会出现同一时段同时充放电；代码会独立检查该现象。

## 5. 与论文结果对应

按当前数据与上述口径，参考求解结果为：

- 全天购电量：约 `59482.699 kWh`
- 全天购电费：约 `35126.949 元`
- 无储能基准费用：约 `48052.047 元`
- 节省费用：约 `12925.098 元`
- 节省比例：约 `26.90%`
- `0:00` 与 `24:00` 储电量均为 `6000 kWh`
- SOC全过程满足 `1200 ~ 10800 kWh`

## 6. result1 模板时间标签说明

官方 `result1.xlsx` 的144个时间标签与附件1的右端点标签存在一个10分钟的显示差异。  
为了不破坏官方模板结构，本代码保留模板标签不变，并将144个求解结果按模板数据行顺序写入。

论文正文中的时间区间解释应统一采用“第五章 数据预处理”中已经确定的右端点口径。
