# 2026 高教社杯全国大学生数学建模竞赛 C题——问题三全部 MATLAB 代码

## 1. 文件说明

- `run_q3_all.m`
  一键九步流程：配置 → 预报 → 求解 → 校验 → 官方模板 → 论文表 → 配图 → 实验 → 交叉校验。
- `run_q3_all_fast.m`
  同上但跳过第 8、9 步（实验与交叉校验），用于快速跑通。
- `q3_config.m`
  **口径唯一真源**：罚则系数（0.5 / 1.5 / 5）、三个临界分位（0.80 / 0.70 / 0.90）、
  降尺度方法、四个预报时刻的开关、情景数、日末 SOC 口径。改口径只改这里。
- `q3_forecast.m`
  负载自预测（与问题二同一套）+ 附件3 整点预报解码（列语义 `k = h − τ + 1`，跨日）
  + 降尺度到 10 分钟。输出四套净负荷预报（四个发布时刻各一套），并做三项自检。
- `q3_lp.m`
  通用阶段 LP 内核：给定价格向量、时域、SOC 起点、情景集、可选的计划量 `G`，
  解出该阶段的 `(A, C, D, e, curt)`。四个阶段共用这一个内核。
- `q3_solve.m`
  四阶段滚动求解器（0:00 定计划，6/12/18 各调整一次）。
  ⚠️ 落盘由**显式开关** `qc.saveSolution` 控制，默认**不写**——原因见第 5 节。
- `q3_validate.m`
  五层校验（结构不变量 / 物料守恒 / 费用复算 / 模型论断 / 交叉校验）+ 四档基准对照。
  会被问题四借用（用 `priceMode='volatile'` 校验 `result4-3`）。
- `q3_export_result3.m`
  生成官方模板 `out/result3.xlsx`（4 张表）与 `out/result3_填写说明.txt`。
- `q3_paper_tables.m`
  生成论文表（四个指定日期）+ 逐月汇总，落 `out/paper_q3_*.csv`。
- `q3_visualization.m`
  生成 6 张论文配图到 `out/figures/`。
- `q3_crosscheck.m`
  **只读交付文件、不读源码**的独立复算：从 `out/result3.xlsx` 反向验证守恒律与费用。
- `t_q3_ablation.m`
  开放题实验：① 预报时刻消融（A0/A1/A2/A3）；② 预报来源对照（自预测 / 附件3 / 混合）。
- `t_q3_downscale.m`
  降尺度三法对比（`stair` / `linear` / `shape`）的费用与 RMSE。
- `t_q3_granularity.m`
  口径 3 敏感性：调整量逐 10 分钟结算 vs 全天总量结算。
- `t_q3_term_policy.m`
  口径 2 对照：日末 SOC 固定 6000 vs 放开末槽（含按价作价）。
- `t_q3_planquant.m`
  计划分位数扫描（**60 天子区间**）。
- `t_q3_reading.m`
  费用读法 A/B 对照（**60 天子区间**）。
- `t_q3_lpcoef.m`
  LP 计价系数敏感性（**60 天子区间**）。
- `dev_scratch/`
  开发期临时调试脚本（含 `measure_pdf.py` 与实验日志）。**不属于交付物**，保留仅供追溯。

## 4. 本问的建模口径

| 口径 | 取值 | 依据 |
|:---|:---|:---|
| **口径 4 费用读法** | 计划部分按全额、差额按 0.5×/1.5×（读法 B） | 题面「违约电价是交易时刻电价的 50%」的字面语义；读法 A 会反而收 1.5 倍，且把计划分位拉到 0.25 量级 |
| **口径 3 调整量结算粒度** | **逐 10 分钟**（另附全天总量对照） | 贴合题面逐时段语义，且官方模板按 10 分钟给数。**两者差 23.161%，需队内定死** |
| **口径 2 日末 SOC** | 固定 $S_0 = S_{144} = 6000$ kWh | 沿用问题二，保证四问可比；放开闭环已验证更贵（+1.636%） |
| **口径 5 附件3 列语义** | 第 k 列 = `[发布时刻+(k−1)h, 发布时刻+k·h)`，跨日 | 预处理阶段对拍标定 |
| **口径 7 信息集** | 附件3 官方光伏预报 + 自预测负载 | 附件3 只给光伏，不含负载 |
| 降尺度方法 | `shape`（另附 `stair` / `linear` 对照） | 三法最大差 0.290%，不敏感 |
| 情景数 $n_S$ | 30（附件3 最近 30 天的预报残差） | 与问题二一致，便于对照 |

> 口径 3/6/7 在 `p0_config.m` 中仍是【待定】占位。本问**不修改** `p0_config.m`，
> 把取值写在 `q3_config.m` 并注明来历，供队内复议。

## 5. 模型要点

1. **四个问题是一族报童问题**，临界分位 = `1 − c_边际 / c_紧急`：
   计划 `1 − 1/5 = 0.80`；调整上侧 `1 − 1.5/5 = 0.70`；调整下侧 `1 − 0.5/5 = 0.90`。
   调整量闭式：`A_t = min( max(G_t, Q_0.70), Q_0.90 )`。
2. **临界分位与电价无关**：`p_t` 在分子分母同时出现而被约掉。
   于是逐日电价（问题四）改变的是 LP 的 `(c,d)` 权衡，**不改变分位规则**。
3. **两步求解严格等价**：申报量 `A_t` 不进 SOC 递推 ⇒ 其最优是一段**区间**；
   先解 LP 定 `(c,d)`、再用闭式分位覆盖 `A`，与联合求解完全等价（逐槽偏差恰好 0）。
4. **弃电有三个来源**：超买、多放、光伏富余。三者可重叠；
   「无来源的弃电」计数为 0 是分解完备性的检验。
5. **⚠️ 落盘是显式开关**：`q3_solve.m` 默认**不写** `q3_solution.mat`，
   只有 `run_q3_all.m` 里 `qc.saveSolution = true` 的正式全量跑才落盘。
   **原因（真实事故）**：诊断脚本（消融、降尺度、粒度、闭环、分位扫描、系数扫描）
   会以各种派生配置反复调用 `q3_solve`；落盘若是无条件，交付解就会被最后一次诊断的结果覆盖。
   本队已中招一次（交付的 14 724 901.09 元被写成 60 天子区间的 2.55e6 元残件）。
   **写新实验脚本时请沿用同样的隔离原则：绝不让实验写进交付 outdir。**

## 8. 与问题二、问题四的关系

- **与问题二**：本问计划量的分位（0.80）与问题二**同源同值**，故 A0 组（不调整）
  的费用 14 973 481.43 元可与问题二的框架直接对照。

  两问共用同一求解器，差异只可能来自电价输入，是可解释的受控对照。
