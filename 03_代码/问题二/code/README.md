# 2026 高教社杯全国大学生数学建模竞赛 C题——问题二全部 MATLAB 代码

## 1. 文件说明

- `run_q2_all.m`  
  一键执行全部流程（8 步）。

- `q2_config.m`  
  **问题二口径声明**（本问最要紧的文件）。物理参数一律继承 `p0_config`，本文件只追加
  问题二特有的设定，并把四条口径的取值与理由写在文件头。换口径只改这里。

- `q2_forecast.m`  
  日前预测：负载用 `0.5×上周同日 + 0.5×近4周同星期几均值`，光伏用 `近7日同时刻均值`。

- `q2_solve.m`  
  两阶段随机规划求解：第一阶段定计划购电量与充放电，第二阶段按情景做紧急购电/弃光回收。

- `q2_oracle.m`  
  完美信息基准（费用下界）：单日 LP，事后已知当天真实负载与光伏。用于量化「预测误差的代价」。

- `q2_validate.m`  
  四层独立校验（结构不变量 / 守恒律 / 费用复算 / 模型论断），并给出两个基准对照。

- `q2_export_result2.m`  
  将结果写入官方 `result2.xlsx` 模板（三张表：计划购电量、充放电量、紧急购电量）。

- `q2_paper_tables.m`  
  生成论文里的表 1 / 表 2 / 表 3 及四日收支汇总。

- `q2_visualization.m`  
  生成 6 张论文配图，全部可用这一个脚本复现。

- `t_forecast_backtest.m`  
  预测方法选型的回测依据（`q2_config` 里负载/光伏方法的选取来源）。

- `t_q2_term_policy.m`  
  口径 2 敏感性实验：日末 SOC 固定 6000 vs 日界自由，量化「日末闭环」的代价。

- `dev_scratch/`  
  开发期临时调试脚本（探模板结构、定位 bug 用），**不属于交付物**，保留仅供追溯。

## 4. 本问的建模口径

物理参数与问题一完全一致（10 分钟步长、`dt = 1/6 h`、效率 0.90、SOC 区间 1200~10800 kWh、
最大充放电功率 5000 kW、不允许向电网售电、富余光伏可弃）。问题二**特有**的四条口径：

| 口径 | 取值 | 依据 |
|---|---|---|
| 7 信息集 | **严格字面**：只用附件1 + 附件2 | 问题2 题面只写「根据附件1 中的电价和附件2 中的数据」，未引用附件3（附件3 也【没有】负载预报）。代价是负载与光伏都必须自预测，好处是模型与题面信息结构严格对应 |
| 2 日末 SOC | **固定 6000**：`S_0 = S_144 = 6000` | 与问题一一致；电价逐日相同 ⇒ 跨日搬运储能无套利空间，日末回到起点近乎不失最优（实测代价见 `out\q2_term_policy.txt`） |
| 6 附件5 模板填充 | **positional**：不改模板标签，第 i 个数据位写本队第 i 个时段 | 模板标签整体错位一个槽（`probe_a5.m` 已实证）。与队友 Q1 处理方式一致，保证 result1/2/3 内部自洽 |
| 3 结算粒度 | **本问不需要** | 题面已直接规定「其他时间段的购电费用均按计划购电量计算」，无调整电量 |

**单位**：全部为 **kWh（能量）**，即 `kWh = 功率 × dt`。与附件5 模板自身的「单位：kWh」一致，
也与队友 Q1 的 `q1_solution.csv` 一致。

## 5. 模型要点

**两阶段随机规划。** 第一阶段（日前）定计划购电量 `g` 与充放电 `c, d`；
第二阶段（实时）按情景取紧急购电 `g^em = max(0, N^s + c - d - g)` 与弃光 `e = max(0, g + d - c - N^s)`。
负载与光伏在约束和费用中只以差值 `N = L - PV` 出现，故**随机性完全由净负荷承载**。

**报童临界分位。** `g_t` 不进入 SOC 约束，目标对 `g_t` 的导数为
`p·dt·(1 - 5·#{s : N^s_t + c_t - d_t > g_t}/nS)`，令其为零得
`#{短缺情景} = nS/5`，即临界分位 `c_u/(c_u+c_o) = (5p-p)/((5p-p)+p) = 4/5 = 0.8`。
nS = 30 时该分位对应第 24 个次序统计量，`g*_t = max(0, z_(24))`。
**关键洞察**：最优计划量是一段**区间（平台）**而非单点——平台上费用恒等，取左端即可。
这一点由 `q2_validate.m` 的 D 组论断逐条数值验证。

**求解简化**：因 `η = 0.90 < 1`，同时充放电严格劣，纯 LP 即可，无需 MILP / 大 M 法。

## 6. 与论文结果对应

按当前数据与上述口径，参考求解结果为：

- 求解区间：2025-02-01 ~ 2025-12-31，共 334 天
- 计划购电量：约 `22,099,227.8 kWh`，计划购电费约 `13,468,138.59 元`
- 紧急购电量：约 `295,713.1 kWh`，紧急购电费约 `1,097,286.86 元`
- 购电费合计：约 `14,565,425.45 元`（期望口径 `14,341,911.70 元`）
- 储能的价值：相对无储能基准节省 `1,841,894.18 元`（降幅 `11.23%`）
- 预测误差的代价：相对完美信息下界多花 `2,320,378.54 元`（升幅 `18.95%`）
- 日末储电量：334 天全部为 `6000 kWh`

## 7. result2 模板说明

官方 `result2.xlsx` 的 `充放电量` 与 `紧急购电量` 两张表**只给了样例行**
（前两天 + 省略号 + 最后一天），必须按 334 天整体重建；`计划购电量` 表才有完整的 334 行。
本代码按模板既有行块结构补齐全部 334 天，且**不修改模板的时间标签**。
序列的填充方式与理由详见 `out\result2_填写说明.txt`。
