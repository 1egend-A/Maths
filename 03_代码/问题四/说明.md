## 🔴 本问最主要的产出是五条反直觉结论（不是那两个数字）

1. **「236 倍峰谷比」是误导性指标**：全期报价标准差只比附件1 大 **7.3%**，
   储能价值只从 19.35% 升到 **19.49%**。
2. **调整机制的价值 = 信息更新的价值**：自预测下 `A_t ≡ G_t` 逐位成立、价值**恒为 0**；
   附件3 下才值 272 412.60 元。调整收益中 66% 来自"把购电量调对"、34% 来自"重排充放电"。
3. **逐日电价并未提高跨日套利价值**（每档窗口都比附件1 省得少：4.685% < 5.084%）。
4. **近零价的 28 个时段实际节省恰好为 0 元**——它们落在 11:00–13:00 的弃光时段，
   净购电量本就为 0；钱全在尖峰侧（削平 p>1 可省 10.471%）。
5. **CVaR 样本外最优在 λ = 0.5，不在端点 λ = 1**——λ 是唯一被拟合的量，
   样本内单调改善、样本外见顶回落。
