## 0. 结论先行：要不要图？要，但只画"能承担论证任务"的图

**要。** 这道题的图有三个不可替代的作用，缺一个都吃亏：

| 作用 | 说明 | 不画图的代价 |
|---|---|---|
| **① 展示数据特征** | 峰谷价差、光伏日内形状、预报质量——这些是**你选这个模型的理由** | 评委不知道你的模型为什么长这样，会当成"套模板" |
| **② 展示机理** | 储能怎么套利、功率怎么平衡、SOC 怎么走 | 纯文字描述调度过程，评委读不下去也验不了 |
| **③ 展示对比与稳健性** | 优化 vs 基准、不同参数的敏感性、样本外表现 | 无法证明"优化确实有效"，这是优化类题的核心得分点 |

**但同时要防两个坑**：

- **坑一：为画而画。** 一张只有 4 个数字的柱状图，不如一句话。**判据：这张图删掉，论证是否变弱？不变弱就删。**
- **坑二：图多字少。** 国赛评分里图不能替代推导。**每张图必须配 1~3 句"这张图说明了什么"**，直接写在图注或正文里。

**规模建议**：正文 **8~12 张主图**（不含附录）。按四问分配大致 2 / 3 / 3 / 2，再加 1~2 张全局汇总。正文页数控制在当年官方格式规范以内，图占的版面要提前算进去。

## 1. 通用规范（先立规矩，避免返工）

### 1.1 MATLAB 出图的三个本机坑

1. **中文乱码**。本机是中文 Windows，MATLAB 默认坐标轴字体不含中文，标题/图例会变成方框。
   ```matlab
   set(0, 'DefaultAxesFontName', 'SimHei');   % 或在每个 axes 上设 'FontName'
   set(0, 'DefaultTextFontName', 'SimHei');
   ```
   **建议**：论文图统一用「中文标题 + 英文轴标签」或全中文，但**必须在脚本里显式设字体**，不要依赖默认。

2. **导出分辨率**。截图贴进 Word 会糊。统一用矢量或高 DPI：
   ```matlab
   exportgraphics(gcf, 'fig_q1_stack.png', 'Resolution', 300);   % R2020b+ 推荐
   % 或 print(gcf, '-dpng', '-r300', 'fig_q1_stack.png');
   ```
   能出 PDF/EPS 矢量图的（折线、柱状）**优先矢量**，位图只留给热力图/散点密集图。

3. **文件名规范**。建议 `fig_q<题号>_<内容>.<ext>`，如 `fig_q1_power_balance.png`。附录里列图清单时不会乱。

### 1.2 配色与可读性

- **不要用红绿对比**做主色（色盲不友好，且黑白打印会糊成一团）。推荐：购电=蓝、放电=橙、光伏=黄绿、充电=紫、SOC=深灰。
- **同一物理量在全文用同一颜色**。Q1 的"购电=蓝"，到 Q3 还得是蓝。评委是顺着读的，换色会制造理解成本。
- **线宽 ≥ 1.5，字号 ≥ 9pt**（缩到 A4 双栏还能看清）。
- 多条曲线叠在一起时，**用线型区分**（实线/虚线/点划线），不要只靠颜色。

### 1.3 每张图必须自带信息

最低要求：**单位 + 图例 + 必要的标注**（如峰值点、约束边界、决策时刻）。坐标轴没单位的图，在评审眼里就是减分项。

## 2. 全题通用底图（建议放"数据预处理"章节，1~2 张）

这两张图**不服务某一问，服务整篇论文**——它们是你所有建模选择的依据。

### 图 0-A：全年电价与负载的热力图（日历图）

- **形式**：x 轴 = 一天 144 个时段，y 轴 = 365 天，颜色 = 数值。左右两张子图并排（左：附件4 电价，右：附件2 负载）。
- **能说明什么**：
  - 电价的**日内峰谷结构**（每天固定时段贵/便宜 → 储能套利空间稳定存在）
  - 电价的**季节性**（哪些月份整体偏贵）
  - 负载的**周末效应 / 季节性**（如果热力图上能看到条纹，就是有力证据）
- **数据**：附件4 `D.actual.price` (365×144)、附件2 `D.actual.load` (365×144)。**已归一化在 `data.mat` 里，直接可用。**
- **为什么值得画**：这张图一眼就把"储能为什么能赚钱"讲清楚了，比三段文字都强。

### 图 0-B：附件1 典型日三线图（电价 / 负载 / 光伏）

- **形式**：双 y 轴。左轴 = 功率 (kW)，画负载与光伏；右轴 = 电价 (元/kWh)，画阶梯线。
- **能说明什么**：
  - 峰值电价时段（**第 124 时段 = 20:40**，1.3952 元/kWh）与光伏出力（白天）**错峰**——这是本题的核心矛盾：**最需要用电的时候光伏没有，光伏最多的时候又不缺电**。
  - 负载晚高峰与电价高峰重合 → 储能放电的价值点。
- **已实测数字可直接标注**：电价 0.3713 ~ 1.3952 元/kWh（峰谷比 **3.76**）；负载 3309.39 ~ 5958.97 kW；光伏 0 ~ 7612.32 kW（**仅 89 个时段非零**）。
- **加分细节**：在图上用浅色阴影标出"光伏非零时段"与"电价高峰时段"，两者不重叠的事实立刻可见。

## 3. 逐问配图建议

### Q1 · 单日确定性优化（建议 2 张主图 + 1 张备用）

> Q1 是单日 LP，变量 432 / 约束 432。这一问图的任务是**把"优化到底做了什么"画出来**。

#### 图 1-A：最优功率平衡堆叠图 ⭐ **必备**

- **形式**：x 轴 = 144 个时段，上下分栏共用 x 轴。
  - 上栏（供给侧）：堆叠面积/柱 —— 电网购电、储能放电、光伏 三段叠加，顶部叠一条负载曲线
  - 下栏（去向侧）：堆叠 —— 负载、储能充电
- **能说明什么**：**功率平衡约束 `g + d + PV = L + c` 被逐时段满足**，且能看到"什么时候放电、什么时候充电"。这是 Q1 全部结论的载体。
- **注意**：充电段（`c>0`）与放电段（`d>0`）**不应重叠**——这正是"η<1 时同时充放次优、纯 LP 免 MILP"的可视化证据。可以在图注里点明这一点（验收报告里冲突时段 = 0）。

#### 图 1-B：SOC 轨迹 + 电价叠加图 ⭐ **必备**

- **形式**：双 y 轴。左轴 = SOC (kWh)，并画出 `S_min=1200` 与 `S_max=10800` 两条**水平虚线边界**；右轴 = 电价。SOC 用粗实线。
- **能说明什么**：
  - SOC 轨迹与电价曲线**反向同步**——电价低谷（如夜间）充、高峰放，储能套利的直接证据。
  - SOC 是否触到 1200 / 10800 边界 → 说明约束是否 binding。
- **加分**：把 SOC 曲线按"充电段/放电段"上色，或在与电价峰值对齐处加竖直参考线。

#### 图 1-C：优化 vs 无序购电基准 对比（备用/可并入表格）

- **形式**：分组柱状图或简单折线，对比两者的单日总费用与峰值购电功率。
- **能说明什么**：**"储能套利价值"这个数字**——优化省了多少钱。这是 Q1 最想回答的问题。
- **取舍**：如果只有两个数字，**建议直接写成正文一句话 + 表格，不必单独出图**。除非还要对比多条曲线（如逐时段购电差异）。

> ⚠️ **依赖待定口径**：Q1 若采用日末 SOC 闭环（口径 2），SOC 轨迹的终点会明显不同。**口径未定前画的图标记为草图**，别在正文里断言具体数值。

### Q2 · 日前计划 + 5 倍紧急购电罚则（建议 3 张主图）

> Q2 的性质变了：从"确定性"变成"**不确定性下的决策**"。所以图要从"画调度"转向"**画分布、画权衡、画误差**"。

#### 图 2-A：报童临界分位示意图 ⭐ **必备**

- **形式**：x 轴 = 决策的计划购电量（或计划充电量），y 轴 = 期望总成本。画一条 U 形成本曲线，**标出最小值的位置**，用两条竖虚线标出"临界分位 = 4/(4+1) = 0.8"对应的点。
- **能说明什么**：这是 Q2 的**理论骨架**。5 倍紧急购电价 ⇒ 缺电代价 : 多买代价 = 4 : 1 ⇒ 临界分位 0.8 ⇒ **宁可略多买**。一张图把"为什么最优解偏向保守/激进"讲透。
- **加分**：在同一张图上叠一条"成本对决策量的导数"曲线，在零点处与最优解对齐，展示一阶条件。

#### 图 2-B：紧急购电量分布图 ⭐ **必备**

- **形式**：直方图（或核密度曲线），x 轴 = 单日紧急购电量 (kWh)，纵轴 = 频数。可叠加一条竖线标均值/中位数。**更推荐做成"334 天逐日紧急购电量"的散点/折线 + 分布直方图的双联图。**
- **能说明什么**：
  - 紧急购电**是否非平凡**（大部分不为零 → 说明"信息集"设定合理，罚则真正起了作用）
  - 分布的**长尾**（少数天极端缺电，正是罚则要防的情形）
- **⚠️ 这张图是口径 7 的"体检报告"**：若选 `oracle`（假定已知当天实际值），这张图会变成一根贴地的平线——**图本身就证明了该口径让问题退化**。所以这张图也能拿来做对照实验。

#### 图 2-C：334 天累计费用曲线（优化 vs 基准）⭐ **必备**

- **形式**：折线图，x 轴 = 日期，y 轴 = 累计费用 (元)。至少两条线：优化策略、无序购电/纯现货基准。
- **能说明什么**：两条线的**斜率差**就是每天省的钱，**终点差**就是全周期总收益。比一个"总费用 XXX 元"的数字有说服力得多。
- **加分**：把逐日费用差额做成下方的小幅柱状图（正=省钱、负=亏），一眼看出哪些天优化反而吃亏（通常是预报偏差大的天）。

#### 图 2-D：预测误差诊断图（备用）

- **形式**：预测值 vs 实际值的散点（叠 y=x 参考线），或误差的直方图。
- **能说明什么**：Q2 里"计划"和"实际"的差距从哪来。**注意这会牵出附件3 的数据质量问题**（官方预报 RMSE 644.72 打不过"照抄昨天"的 417.72，高约 54%）——如果你在论文里用了这个发现，**必须配图**，否则这么反直觉的结论没人信。
- **建议形式**：三条曲线的误差对比（附件3 单用 / 持续性 / 混合 w=0.2），横轴 = 时段，纵轴 = 误差。或直接一张 RMSE 对比柱状图 + 一句解释。

> ⚠️ **依赖待定口径**：口径 7（信息集）直接决定 2-B / 2-C 长什么样。**如果队内最终选 `forecast`，这三张图都是核心图；如果选 `oracle`，2-B 退化成平线、要换成对照说明。**

### Q3 · 滚动调整 + 非对称罚则（建议 3 张主图）

> Q3 又多了一层：**同一笔偏差，多买和多卖的罚则不对称**（0.5× / 1.5×）。图要突出"**非对称**"这三个字。

#### 图 3-A：滚动调整时间轴示意图 ⭐ **必备**

- **形式**：横向时间轴，标出 0:00 / 6:00 / 12:00 / 18:00 四个**决策时刻**，每个时刻画一个"已过去 / 待决策"的分界，并在下方画出该时刻能看到的预报视野（附件3 的 24 小时窗口）。
- **能说明什么**：一眼讲清"滚动的信息结构"——**每个决策点只用当时已知的信息**。这是 Q3 与 Q2 的本质区别，也是评委最想确认你有没有真的做对（有没有偷偷用未来信息）。
- **这张图价值极高**：纯文字讲"滚动"很啰嗦，一张图就够。

#### 图 3-B：非对称罚则的分段成本函数图 ⭐ **必备**

- **形式**：x 轴 = 实际与计划的偏差量 Δ（正=多买，负=少买），y 轴 = 罚金。画一条**斜率不同的折线/分段直线**：Δ>0 段斜率 = 0.5×，Δ<0 段斜率 = 1.5×。
- **能说明什么**：**"不对称"的直接可视化**。这条折线是 Q3 模型的全部特征，画出来比任何公式都直观。
- **加分**：把 334 天实际的偏差**散点**打在横轴上（纵轴贴底），可以看出实际偏差落在哪个区间、被罚多少。

#### 图 3-C：调整前后对比图 ⭐ **必备**

- **形式**：挑一个**有代表性的日子**（建议选偏差最大的一天），画三组曲线对比：原始计划购电量 / 调整后购电量 / 实际需求。再叠一条下方的差额柱。
- **能说明什么**：滚动调整**具体改了什么**。挑最极端的一天，效果最明显。
- **加分**：同一格式画 2~3 个典型日（偏差大 / 中 / 小），做成 2×2 小多图（small multiples），展示策略的普适性。

#### 图 3-D：敏感性与稳健性图（备用，但很值钱）

- **形式**：x 轴 = 罚则系数比（或 `adjGranularity` 的两种设定），y 轴 = 总费用/总罚金。画成折线或热力图。
- **能说明什么**：**结论对参数不敏感 = 稳健**，这在评分里是加分项。反过来也能诚实说明"哪一段参数会让结论翻转"。

> ⚠️ **依赖待定口径**：口径 3（调整量结算粒度：逐 10 分钟 vs 全天总量）**直接决定 3-B 的横轴是逐时段偏差还是日总量偏差**。这条口径没定之前，3-B 只能画示意图，不能画真实数据。

### Q4 · 波动电价下的风险决策（建议 2~3 张主图）

> Q4 的关键词是**风险**。图必须能回答："你为了降风险，付了多少收益的代价？"

#### 图 4-A：电价场景扇形图 ⭐ **必备**

- **形式**：x 轴 = 时段（或日期），中间一条**中位/均值轨迹**，上下用逐渐张开的半透明色带表示分位数区间（如 10%~90%、25%~75%）。若用的是场景法，直接画多条浅色场景线 + 一条加粗均值线。
- **能说明什么**：**不确定性有多大、在哪些时段最大**。这是 CVaR / 鲁棒优化的建模前提。
- **注意**：附件4 电价实测 0.0076 ~ 1.7936 元/kWh，**中位数 0.7385**，且 **<0.10 的极端低价有 28 个时段**（<0.05 有 9 个）。扇形图要能把这种**尖峰/深谷**体现出来，不要用高斯假设抹平。

#### 图 4-B：CVaR 有效前沿 ⭐ **必备**（若走 CVaR 路线）

- **形式**：x 轴 = 风险（CVaR 或标准差，单位：元），y 轴 = 期望收益（或期望费用）。扫描风险厌恶系数 λ，画出每个 λ 对应的点，连成**有效前沿曲线**。在曲线上标出几个代表性 λ 值对应的点。
- **能说明什么**：**风险-收益权衡的完整图景**。曲线上每一点都是一个可选策略，"拐点"处就是性价比最高的 λ。
- **加分**：把"不考虑风险（λ=0）"的点单独标出，用一条虚线示意它到前沿的距离——直观展示**"降风险要付多少代价"**。

#### 图 4-C：稳健性样本外检验图（强烈建议）

- **形式**：柱状图或箱线图，对比不同策略（确定性最优 / CVaR / 鲁棒 / 基准）在**测试期**的费用分布。
- **能说明什么**：**优化不是过拟合**。这是优化类论文最容易被打的地方——"你在训练集上最优，样本外呢？"
- **加分**：箱线图能同时展示中位数和尾部风险，比柱状图信息量大。

> ⚠️ 这条题的路线的选择（CVaR vs 鲁棒优化 vs 场景法）**属建模决策**，本文件不预设。**上面 4-B 走 CVaR 版；若走鲁棒优化，换成"不确定集大小 vs 最坏情形费用"的曲线；若走场景法，换成"场景数 vs 解稳定性"的收敛图。**

## 4. 全局汇总类图（1~2 张，放"模型评价"或"灵敏度分析"章节）

### 图 5-A：参数敏感性热力图

- **形式**：x 轴 = 参数 A（如 η、罚则系数），y 轴 = 参数 B，颜色 = 总费用（或总收益）。或单参数扫描画成折线 + 误差带。
- **能说明什么**：**哪些参数真正影响结论、哪些无所谓**。这是"模型评价"章节的硬通货。
- **建议扫描的参数**：储能效率 η(0.9 附近)、P_max、容量、报童临界分位、罚则系数比。**注意：口径类参数（如日末 SOC）的扫描要单独说明，那是口径对照而非灵敏度分析。**

### 图 5-B：四问结果汇总图

- **形式**：一张 2×2 小多图，或一张横向对比条形图，把 Q1~Q4 的核心结论并列。
- **能说明什么**：**帮评委回顾**。放在结论章节前面，效果很好。

## 5. 不建议画的图（反例清单）

| 反例 | 为什么不要 |
|---|---|
| 只有 2~5 个数值的柱状图 | 不如写一句话或放表格，占版面且无信息量 |
| 3D 曲面图（除非真有 3 个自变量） | 绝大多数情况是为了"看起来高级"，实际更难读 |
| 饼图（占比 > 5 项的） | 人眼比较角度的精度极差，用条形图 |
| 未设随机种子的散点/随机结果图 | 复现性存疑，评委问"这张图能重复出来吗"很难答 |
| 直接从 MATLAB 截图贴进论文的 | 分辨率不够、带软件边框，专业性打折 |
| 数据探查阶段的所有图都往论文塞 | 论文不是工作日志，只放**承担论证任务**的图 |

## 6. 优先级与时间预算

按"性价比"排序，比赛时间紧时从上往下砍：

| 优先级 | 图 | 对应问 | 预估工作量 |
|---|---|---|---|
| **P0 必画** | 0-A 全年热力图、1-A 功率平衡、1-B SOC轨迹 | 通用/Q1 | 2~3 h |
| **P0 必画** | 2-A 报童分位、2-C 累计费用对比 | Q2 | 2~3 h |
| **P0 必画** | 3-A 滚动时间轴、3-B 非对称罚则折线 | Q3 | 1~2 h |
| **P1 强烈建议** | 2-B 紧急购电分布、3-C 调整前后对比 | Q2/Q3 | 2~3 h |
| **P1 强烈建议** | 4-A 场景扇形、4-B CVaR 有效前沿 | Q4 | 2~3 h |

## 7. 三条硬提醒

1. **图必须先有数据、再有图。** 目前 `数据预处理代码/out/` 里只有**预处理阶段**的产物（归一化数据 `data.mat`、形状权重 `pv_shape.mat`、验收报告）。Q1~Q4 的**求解结果还没跑出来**，所以本文档里的 Q1~Q4 建议图**目前都还没有数据可画**——它们是给建模阶段的产出配的。

2. **待定口径会改变图的形状。** 口径 2（日末 SOC）、口径 3（调整量粒度）、口径 7（信息集）三条未定，直接影响 1-B、2-B、3-B 三张图。**建议：口径定死之前，只画数据探查类的图（0-A、0-B、2-D），求解结果类的图先别定稿。**

3. **每张图都要能在答辩时讲 30 秒。** 准备一句话说明"这张图是什么、说明什么、数据从哪来"。讲不出来的图，就是该删的图。
