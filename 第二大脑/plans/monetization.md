# 变现计划

## 结论先行

成本不是瓶颈，需求才是。按 API 官方价测算，省着跑约 ¥2–4 / 小时，放开跑 ¥10–20 / 小时；做产品是一次性投入，摊到多次销售。真正的风险是产品没人买和时间不够。

## 路线选择

四条路：外包接单 / 数字产品 / 自媒体流量分成 / 卖现成工具模板。

选定 **数字产品 + 工具模板**：把已有的 A 股报告模板、回测脚本、HTML 报告规范等打包成可上架的数字产品，定价参考 ¥19.9–99。

## 合规红线

面向公众收费提供个股买卖建议需要证券投资咨询牌照。**只能卖方法、代码、数据、模板、报告流程，绝不卖「跟着买这只」**。不承诺收益，不伪造成绩。

## 成本控制习惯

- 复用已有结论，不重读已知文件。
- 单任务单会话，长会话等于背着全部历史付费。
- 任务前先锁范围，不漫游、不反复润色。
- 重活放到空闲时段跑。
- 默认用便宜的快模型（flash 档）做主力，贵模型只留给高价值原创任务；真要切换先做同范围并排实测，比质量、比账单、比迭代轮数。
