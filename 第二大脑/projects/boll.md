# BOLL 通道工作流

## 定位

与旧 A 股工作流**完全独立**的自包含目录，结构照搬（参数中心 + pipeline + JSON + MD/HTML），核心逻辑换成**纯规则**。改动它不会影响旧工作流的任何脚本。

离场规则沿用旧工作流的 ATR 那套（止损 min(1.5×ATR, 8%)、止盈 min(3×ATR, 20%)、持有 13 天），这样两套策略可以直接对照。

## 三条硬条件

1. **通道向上**：中轨最近 15 个值的线性回归斜率 > 0。
2. **触轨 + 反弹**：近 3 个交易日内任一日「最低价 ≤ 当日下轨」，且近 5 日收盘价线性回归斜率 > 0。
3. **估值**：0 < PE_TTM < 60（亏损股不通过）。

- BOLL 参数：N=20、K=2、标准差用**总体标准差**（ddof=0）。
- 排序：中轨日均斜率占中轨的百分比降序，并列看 5 日涨幅。
- **刻意不加**市值 / 换手率 / 排除涨停这类初筛——加了就选不出目标票。

## 已知限制（报告必须一起披露）

1. **股票池是旧快照**（7-30），此后新上市的股票不在池内；全 A 接口当天连不上。
2. **PE / 价格快照只能是运行当日的**，所以运行日期必须等于最新交易日；历史复盘要显式允许过期，且 PE 会穿越。
3. 触下轨 ≠ 见底，下行趋势里可能是下跌中继。
4. 日 K 原始口径，区间内除权除息会让 BOLL 失真。
5. 条件 2 用的是「5 日收盘斜率 > 0」而非「5 日涨幅 > 0」——斜率正、端点为负的票也能通过；要更严可以加「5 日涨幅 > 0」或触轨深度下限。
