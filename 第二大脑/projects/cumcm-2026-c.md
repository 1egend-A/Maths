# 国赛 C 题

## 题目结构

单日微型电网购电优化，逐问加复杂度：
- Q1：单日线性规划。
- Q2：日前计划 + 5 倍紧急购电惩罚（报童式）。
- Q3：滚动 / 两阶段调整（0.5 倍与 1.5 倍非对称罚则）。
- Q4：实时波动电价（CVaR / 鲁棒优化做差异化）。

实现全部用 MATLAB（本机环境限制见 `toolchain/environment.md`）。

## 关键结论

1. **「弃电」变量从未真正起作用**。第一版按直觉把它写进约束，核对后发现在整条链路里多余；最终论文里它只是一个事后核算量（同期光伏发电量的 16.40%）。
2. **官方光伏预报打不过「照抄昨天」**：RMSE 644.72 vs 417.72；混合最优权重 0.2 时 385.79。且预报值疑似被饱和截断在约 996 kW 上限附近。
3. **附件 3 的语义是「预报 k 小时 = 发布时刻起算的第 k 小时」**，行内 24 列跨日。用「第 k 列 vs 当日第 k 小时」直接算相关，会得到负相关——那是比较方式的假象，不是数据错位。
4. **日末闭环在数据上留下指纹**：晚高峰充电量 334 天完全相同（标准差 0），因为电价谷底必触 1200、而口径要求 24:00 回 6000，电网侧必须补固定电量。
5. **「g=0 的时段」是电价高位，不是午间谷价**——模型在那里宁可放电也不买电。这一条我最初讲反了，被自己写的核对脚本抓回来。

## 五条反直觉结论（Q4）

1. **236 倍峰谷比是误导性指标**：全期报价标准差只大 7.3%，储能价值只从 19.35% 变到 19.49%。决定套利价值的是分布离散度，不是极值之比。
2. **调整机制的价值 = 信息更新的价值**：自预测下调整量与被调整量逐位相同，价值恒为 0；只有给了外部预报才有价值。
3. **逐日电价并未提高跨日套利价值**：每一档窗口都比固定电价省得少——电价逐日完全相同时，跨日搬运无价差可套。
4. **近零价时段实际节省恰好 0 元**：都落在弃光时段，净购电本为零；钱全在尖峰侧，削平高电价时段省了约 10.5%。⇒ 价格风险是单边的。
5. **CVaR 的样本外最优权重在中间不在端点**：样本内单调改善、样本外见顶回落——又一个「单窗口调参必然过拟合」的实证。

## 交付事故（都写进了源码留痕）

1. **跨问转调覆盖了上一问的校验报告**。调用方写了注释想让它写到新目录，但被调函数自己解析路径、无视传入配置 ⇒ 新数字写进了旧报告。**教训：调用方写防御性注释 ≠ 防御生效。**
2. **凭字段名猜语义**：一个名为「调整后」的字段被猜成状态量，实际是费用列；MATLAB 线性索引照单全收不报错，表格里印出「6000 / 6750」。**教训：字段语义不能靠名字猜；形状错了不会报错。**
3. 自检断言本身也会错：断言失败时先问「是不是前提错了」，别急着改被断言的对象。
