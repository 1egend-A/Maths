## 任务一：期货品种信息检索与产业链梳理

- 按板块分工梳理品种信息，统一 10 列框架：品种 / 交易所 / 核心用途 / 产业链位置 / 主产国 / 进出口依赖 / 产区消费区 / 价格影响因素 / 上下游 / 替代品种。
- 把 5 个分散 Excel 汇总成一张 13 品种、5 板块的总表（造纸链、畜牧养殖、木材人造板、软商品纺织、生鲜干果油料），表头冻结、板块分色。
- 补齐信息偏薄的品种（白糖、棉花、棉纱、苹果共 8 列），使每个品种的信息深度统一到 1300–2015 字符区间。
- **价值**：建立「一个品种要回答哪些问题」的固定清单，这是后来做基差与价差研究的基础。

## 任务二：量化交易策略设计与回测

- 平台：真格量化；频率：分钟；基准：商品 CFCI；区间 2023-08 至 2026-07；初始资金 50 万。
- 策略：双均线 + RSI 过滤 + ATR 止损止盈 + 移动止损 + 最大持仓 K 线数。
- 迭代到 v4：**只改长均线 10 → 20**（MA(5,20)），结果全面优于 v3：

| 指标 | v3 MA(5,10) | v4 MA(5,20) |
|---|---|---|
| 累计收益 | 92.53% | **101.66%** |
| 年化 | 24.38% | **26.31%** |
| 最大回撤 | 25.23% | **19.51%** |
| 夏普 | 0.892 | **1.188** |
| 手续费 | 90,393 | **51,973（−42.5%）** |
| 交易数 | 1,614 | **999（−38.1%）** |

- 机理：拉长均线过滤噪声假信号 → 交易频率下降、手续费腰斩、持仓周期 +75% → 增收又降险的帕累托改进。
- **价值**：理解了参数敏感性——单参数微调能同时改善收益与风险，也说明回测结论对窗口与参数高度敏感。

## 任务三：螺纹钢基差贸易策略诊断与优化

- 数据：5 个城市的螺纹钢基差，864 天。
- 先做数据体检：现货缺失时基差列等于负的期货价（硬伤），用前值填充并重算修复；列名编码混编一并处理。
- 半衰期差异极大：两个城市 3.2 天，一个城市 21.9 天 ⇒ 同一套参数不能通用。
- v3 结果：累计盈亏 **+12.2%**，盈利因子 **2.97 → 3.89**，止损次数 **−15.1%**。
- 已知局限：某城市趋势过滤过度（交易 −39%，是唯一回撤城市）、未计交易成本、无收敛的经济学约束、缺时间止损。

## 方法论沉淀

1. **先体检再建模**：基差数据里「现货缺失 = 负期货价」这种硬伤不查，后面全是假信号。
2. **同一套参数不能跨标的通用**：半衰期差 7 倍，参数必须按品种/城市分别验证。
3. **参数敏感性的另一面**：单参数微调带来帕累托改进，说明结论可能脆弱，必须看多窗口。
4. **研究报告要写局限**：交易成本、经济学约束、时间止损，缺哪项就明写。
