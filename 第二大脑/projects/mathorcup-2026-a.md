# MathorCup 赛道 A

## 题目

从啤酒的化学成分（227 个特征，其中 9 个是工艺指标）预测感官属性，并做可解释性分析：哪些化合物真正驱动风味、三条建模路径（回归 / 嵌入式 / 网络）能否相互印证。

## 关键口径（已冻结）

- 香气池 **218** = 227 单体特征 − 9 工艺指标；CO2 作边界项另出 217 敏感性；227 只作附表。
- **「同源 ≤2」去冗余规则被实测删除**：同源组内部的 ARI 只有 0.0016，三连同源比例 4.04% 反而低于随机基线 7.99%、p=0.96 ⇒ 语义同族 ≠ 统计冗余。
- 链路模型用弹性网（l1_ratio=0.5，非零特征少于 3 个记「无定义」，不补位）+ 岭回归平行对照。
- 网络路径建在 FDR 图（q=0.05 主 / q=0.001 敏感性）上，双阈值都报。
- 三条路径的收敛性用三口径报告（全样本中位 / bootstrap 中位 / 零重合占比）：P1↔P2 中位 0.200，P1↔P3 在 50/50 维上零重合 ⇒ **P3 不能当独立第三条证据**。

## 主要结果

- 单变量预测：Spearman ρ 中位 0.3825（45/50 维 ρ>0.2）；二次加权 kappa 0.2280；macro-F1 0.3925；准确率 0.626，仅略高于零信息基线 0.620。
- 28 维可预测 / 22 维不确定 / 0 维不可预测。
- 附件 2 复现 24531/24531 对，最大偏差 1.05e-15。
- A 级特征（三位评审全 ≥0.6）：P1 有 4 个，P2 为 0 个（23 个 C 级），P3 全 C。

## 数字护照制度（本项目的核心工程）

- `state/numbers.json` 是唯一数字真源，每条含值、出处 JSON 路径、引用位置；最终 **333 条**、论文引用面 **198 行**。
- 登记脚本幂等（重复跑不出重复条目），数值全按 JSON 路径读产物、不手抄。
- **只核 `value` 不核 `display` 会漏错**：曾揪出 9 条「显示值是补测前的旧数」，论文照抄那一栏仍会错。收口脚本因此加全量 display 忠实性体检（容忍百分比、百分点、分数、区间、科学计数、哈希前缀六种写法）。
- 复核时发现 31 条引用位置是占位符（写成「论文 5.x」），照它成文会把 29 条第三章的数排进第五章 ⇒ 施工图脚本只列候选，不替人拍板。
