## 基准模型

- 能量流：车轮净机械功 46.19% / 电机损耗 22.73% / 附件与热管理 15.59% / 减速器 5.73% / 逆变器 4.71% / 内阻焦耳热 3.77% / 熵热 1.11% / 摩擦制动 0.16%。回收率 41.1%。
- 五项校验全过：守恒残差 0 J（化学能要按焓定义积分才精确闭合）、惯性净功 1e-15 量级、电机闭式损耗 vs 81 点 MAP 误差 5e-5、步长收敛 dt=0.1 vs 0.02 差 0.041%。

## 两个致命 bug（重写时极易重犯）

1. **回收 / 制动工况符号写反**：把制动时的机械功率取成正值，刹车落进电动分支 ⇒ 能耗虚高 70 倍（1025 kWh/100km）。正解是全程保持「流入为正」的有符号量，按逐步恒等式记账；另需补摩擦制动器，低速回收不可行时余量归摩擦制动。
2. **中心差分加速度必须配本步速度**：加速度用中心差分时，若配梯形速度，离散版「∫v dv」的伸缩性被破坏，会冒出假惯性功（实测 −0.063 MJ）。配本步速度，ΔKE 才落到 1e-16。

## 附件 3 的口径陷阱

附件 3 宏观统计与官方工况逐项吻合（1800 s、最大 114 km/h、平均 28.92、里程 14.467 km），但**逐秒波形不同**：它是分段梯形（20 段行程，匀速平台占 54.1%、怠速 23.8%、减速度可达 −1.94 m/s²），官方是 11 段连续起伏、最大加减速度 ±1.47。⇒ 对外材料不能写「就是官方原始曲线」。
