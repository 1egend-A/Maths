# 简历素材

## 这一层解决什么

项目档案回答「当时怎么做的」，这一层回答「写简历时拿什么出来」。所有素材都从 `projects/` 与 `decisions/` 里提取，数字必须能在项目档案里找到出处。

## 五个文件

| 文件 | 用途 |
|---|---|
| `achievements.md` | 量化成果总表：项目 / 成果 / 数字 / 证据 / 体现的能力 |
| `bullets.md` | 按项目写好的简历条目（中文），可直接粘贴；附英文速写 |
| `skills-and-gaps.md` | 技能矩阵：熟练度 / 证据 / 缺口与补强计划 |
| `targets.md` | 目标岗位与匹配度分析 |
| `honors.md` | 竞赛、奖项、证书（含【待补】占位） |

## 内容边界

本仓库公开，**这里只放可公开的成果与描述**。姓名、学校、电话、邮箱、证件号、家庭信息一律不进；正式简历文件（含个人信息）放本地或私有仓库，这里只作为它的素材源。

## 维护时机

项目收尾时同步更新 `achievements.md` 与 `bullets.md`——与「有价值的工作必须回填」是同一条铁律的下半句。投简历前一周再复核 `targets.md` 的匹配度。
