# 求职方向

## 优先级判断

四个方向都能投，但要按匹配度排优先级，不要一份简历投所有岗。

### 1. 量化研究 / 策略研究助理 —— 匹配度最高

- **拿得出手的**：7 版策略迭代、11,883 样本滚动验证、分窗口一致率方法论、完整账本与复盘制度、对过拟合的自觉；**期货公司实习**（策略回测 + 产业链研究 + 基差诊断）。
- **面试会问**：为什么不直接做因子挖掘？答案在 `decisions/lessons.md`——先做了「推翻自己」的训练。
- **要补**：因子研究的系统性（单因子测试框架）、组合优化、实盘撮合经验。
- **风险**：实习偏研究型（策略回测与产业链研究），没有实盘业绩，会被问「你自己赚到钱了吗」，准备好「方法论 > 业绩」的讲法。

### 2. 数据分析 / 数据科学 —— 匹配度高

- **拿得出手的**：口径先行的习惯、数字对账、报告工程化、负结果的处理方式。
- **要补**：SQL 熟练度、业务指标体系的实战、A/B 实验设计。
- **注意**：把竞赛项目翻译成「业务问题」，别一上来讲模型。

### 3. AI 应用工程 / 评测 —— 匹配度中高

- **拿得出手的**：完整的智能体系统、评测集设计与零模型对照、尺子校准、Prompt 工程、记忆体系。
- **要补**：后端工程、模型微调、成本与延迟优化（现在只有实测数字，没有优化过程）。
- **注意**：这个方向最看重「能上线」——审稿智能体的网页版与热更新机制是加分项，讲清楚。

### 4. 工业建模 / 算法（能源、制造） —— 匹配度中

- **拿得出手的**：电力调度、能量流与热管理的实题经验。
- **要补**：运筹优化工程化、仿真软件（Simulink 一类）、工业数据规模下的性能。
- **注意**：这类岗位更看重工程稳定性，把「一致性审计」与「校验残差 0 J」讲细。

## 通用准备清单

- [ ] 一份主简历（研究向）+ 一份分支简历（工程向），共用 `bullets.md` 素材
- [ ] 可展示物：公开的国赛论文与代码（本仓库 `26数模国赛/`）、审稿智能体代码摘要
- [ ] 三个 90 秒故事：一次推翻自己、一次交付事故的修复、一次跨工具协作
- [ ] 每个项目准备「如果重做会怎么改」的答案
- [ ] 面试前重读 `decisions/lessons.md`，那是区分度最高的部分
